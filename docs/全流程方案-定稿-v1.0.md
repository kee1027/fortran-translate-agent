## 硬件前提（约束源头）

- 训练/推理机：6 卡 RTX 5880，**多人共享**，单卡实际可用约 12GB。
- 推论：推理 Q4_K_M（约 5GB）安全；QLoRA 训练（约 12GB）需在他人占用低峰执行，micro_batch=1 + grad_accum=16；任何多卡分布式方案不予考虑。

## 风险与对策（增补）

| 风险 | 对策 |
|---|---|
| 共享显卡训练中被抢占导致 OOM | 训练前 `nvidia-smi` 检查；QLoRA 显存预留 20% 余量；checkpoint 每 100 步保存 |
| 合成数据系统性错误 | 双向编译验证 + 10–20% 人工抽检 + 评测集用真实语料兜底 |
| 微调后灾难性遗忘 | 混入 10–20% 通用指令样本；r=8 对照组 |
| 12GB 卡上 max_len=4096 训练 OOM | 降级路径：max_len=3072 或对超长样本滑窗截断 |
