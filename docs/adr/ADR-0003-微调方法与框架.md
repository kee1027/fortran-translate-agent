# ADR-0003：微调方法与框架 —— QLoRA + LLaMA-Factory

- 状态：已接受（2026-10-19）
- 上下文：共享显卡环境（6 卡 RTX 5880，单卡实际约 12GB），需补充微调实战经验

## 决策

采用 **QLoRA（4bit 基座 + LoRA）+ LLaMA-Factory** 训练框架。

## 理由

1. **QLoRA 是显存约束下的唯一现实选择**：7B 全参微调需 60GB+，不可能；bf16 LoRA 需 24GB+，在 12GB 共享卡上不可行；QLoRA 约 12GB 恰好卡在边界，micro_batch=1 + grad_accum=16 即可。
2. **不跨卡分布式**：6 卡虽在，但共享占用导致可用人卡随时变化，deepspeed/FSDP 多卡方案 fragile。单卡训练对共享环境鲁棒。
3. **LLaMA-Factory 适合"补充经验"目标**：YAML 配置驱动，每个超参显式可见，webui 可看 loss 曲线；出问题文档全。unsloth 速度更快但对多卡/自定义结构支持弱，且隐藏细节不利于学习。

## 超参起点

- r=16, alpha=32, target_modules=all-linear
- lr 1e-4 ~ 2e-4, cosine, warmup 3%, epoch 2–3
- max_len **4096**（Fortran 子程序普遍较长，禁止默认 2048 截断）
- micro_batch=1, grad_accum=16, 4bit NF4 + double quant

## 影响

- 训练配置存 `train/llamafactory_qwen25coder7b_qlora.yaml`。
- 训练产物为 LoRA adapter，部署走 ADR-0004 的合并量化路线。
