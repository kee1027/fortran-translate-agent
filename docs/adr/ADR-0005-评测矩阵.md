# ADR-0005：评测矩阵设计 —— 2×2 对比 + 结构化输出指标

- 状态：已接受（2026-10-19）

## 决策

交付 **2×2 对比矩阵**，并附加 JSON 解析失败率与 token 消耗列：

|  | 单次直译 | Agent 闭环 |
|---|---|---|
| **基座模型（few-shot）** | compile_rate / equiv_rate ① | + avg_iterations ② |
| **微调模型** | ③ | ④ |

## 指标定义

- **compile_rate**：翻译结果过 gfortran / Python 解释器的比例
- **equiv_rate**：数值等价通过率（相对误差容差默认 1e-6，configs 可调）
- **avg_iterations**：闭环平均迭代轮数
- **JSON 解析失败率**：结构化输出需重试的比例（微调收益的直接量化）
- **token 消耗**：端到端成本

## 读数方式（简历主数字）

- ③ vs ① → 微调对直译的增量
- ④ vs ③ → Agent 环路对微调模型的增量
- **④ vs ② → 端到端总收益（写进简历的数字）**

## 评测集规格

- **50 条**，六类语法点各 ≥5 条：数组运算 / DO 循环 / 子程序与函数 / 格式化 I/O / COMMON 块 / 文件读写
- 每条配 `input.txt` + `expected_output.txt`（先跑原始 Fortran 程序生成）
- 与训练集 n-gram 去重隔离（ADR-0002 红线）

## 影响

- `src/eval/` 的 `run_eval.py` 按矩阵输出对比表（Markdown 格式直接贴 README）。
